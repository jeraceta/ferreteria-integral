## 1. Ingreso al sistema

1. Abra el navegador de internet.
2. Escriba la dirección del sistema que le dio el técnico o la administración.
3. Aparecerá la pantalla de inicio de sesión.
4. Escriba su usuario y contraseña.
5. Presione el botón "Ingresar".

Si los datos son correctos, entrará al sistema. Si no, revise que no haya errores al escribir el usuario o la contraseña.

---

## 2. Barra lateral y navegación

En el lado izquierdo de la pantalla está la barra con los nombres de los módulos.

- Haga clic en el nombre del módulo para abrirlo.
- El módulo que está abierto se muestra resaltado.
- Si no ve un módulo, puede ser que su usuario no tenga permiso.

> Esta barra es la guía principal del sistema: desde aquí se accede a todo.

---

## 3. Dashboard

El Dashboard es la primera pantalla que ve después de ingresar.

Aquí puede ver un resumen rápido de la ferretería:

- Ventas del día.
- Total en caja.
- Productos con movimiento.
- Información general para empezar a trabajar.

Use esta pantalla para saber qué está pasando sin necesidad de entrar a cada módulo.

---

## 4. Clientes

Este módulo sirve para registrar y buscar clientes.

Qué puede hacer:

- Agregar un cliente nuevo.
- Buscar un cliente por nombre o cédula/RIF.
- Ver la lista de clientes.
- Corregir datos del cliente.

Cómo usarlo:

1. Abra el módulo Clientes.
2. Pulse el botón para agregar cliente nuevo.
3. Complete los datos (nombre, cédula/RIF, teléfono, dirección).
4. Guarde.

---

## 5. Proveedores

Este módulo administra los proveedores.

Qué puede hacer:

- Añadir un proveedor nuevo.
- Ver el listado de proveedores.
- Buscar proveedor por nombre o por RIF.
- Cambiar datos de un proveedor.

Cómo usarlo:

1. Abra Proveedores.
2. Presione "Nuevo proveedor".
3. Complete la información solicitada.
4. Guarde.

---

## 6. Productos

En Productos se administran los artículos que vende la ferretería.

Qué puede hacer:

- Registrar productos nuevos.
- Ver nombre, marca, código, precio y stock.
- Cambiar datos del producto.
- Consultar el inventario del producto.

Cómo usarlo:

1. Abra Productos.
2. Pulse "Nuevo producto".
3. Ingrese código, nombre, marca, precio y stock.
4. Guarde.

---

## 7. Inventario

Inventario muestra cuánto hay de cada producto.

Qué puede hacer:

- Ver las cantidades disponibles.
- Identificar productos con poco stock.
- Ver el inventario actualizado.

Cómo usarlo:

1. Abra Inventario.
2. Busque el producto que necesita.
3. Verifique la cantidad.
4. Use esta información para ordenar compras o revisar faltantes.

---

## 8. Compras

Compras es el módulo para registrar las compras a proveedores.

Qué puede hacer:

- Registrar una nueva compra.
- Consultar compras anteriores.
- Controlar el ingreso de productos al almacén.
- Generar comprobantes.

Cómo usarlo:

1. Abra Compras.
2. Presione "Nueva compra".
3. Seleccione el proveedor.
4. Ingrese los productos, cantidades y precios.
5. Guarde.

---

## 9. Gestión de Compras

Este módulo sirve para revisar las compras que ya fueron registradas.

Qué puede hacer:

- Buscar compras por fecha o proveedor.
- Ver el detalle de cada compra.
- Confirmar que los productos llegaron correctamente.

Cómo usarlo:

1. Abra Gestión de Compras.
2. Busque la compra deseada.
3. Abra el detalle.
4. Verifique el monto y los productos ingresados.

---

## 10. Ventas

Ventas es el módulo para registrar las ventas al cliente.

Qué puede hacer:

- Registrar una nueva venta.
- Seleccionar cliente y productos.
- Ver el total a pagar.
- Imprimir facturas o comprobantes.

Cómo usarlo:

1. Abra Ventas.
2. Seleccione el cliente.
3. Añada los productos y sus cantidades.
4. Verifique el total.
5. Guarde.

---

## 11. Gestión de Ventas

Este módulo permite revisar las ventas ya realizadas.

Qué puede hacer:

- Buscar ventas por cliente o fecha.
- Revisar facturas antiguas.
- Ver si la venta está pagada o pendiente.

Cómo usarlo:

1. Abra Gestión de Ventas.
2. Busque la venta por número o cliente.
3. Abra el registro.
4. Revise el detalle.

---

## 12. Presupuestos

Aquí se crean presupuestos para ofrecer precios a los clientes.

Qué puede hacer:

- Crear un presupuesto nuevo.
- Agregar productos y cantidades.
- Ver el total en bolívares y en dólares.
- Imprimir el presupuesto.

Cómo usarlo:

1. Abra Presupuestos.
2. Seleccione el cliente.
3. Añada los productos y precios.
4. Guarde.
5. Imprima si desea entregarlo al cliente.

---

## 13. Caja

Caja controla el dinero que hay en la caja.

Qué puede hacer:

- Registrar apertura de caja.
- Ver el dinero ingresado.
- Consultar el saldo de caja.

Cómo usarlo:

1. Abra Caja.
2. Anote el monto inicial.
3. Revise las entradas y salidas.
4. Cierre la caja al final del día si corresponde.

---

## 14. Tesorería

Tesorería controla el dinero y pagos del negocio.

Qué puede hacer:

- Ver los pagos recibidos.
- Registrar movimientos de dinero.
- Consultar operaciones de tesorería.

Cómo usarlo:

1. Abra Tesorería.
2. Revise los pagos registrados.
3. Verifique los montos en efectivo y transferencia.
4. Guarde nuevo movimiento si lo requiere.

---

## 15. Ajuste de Inventario

Este módulo corrige el stock cuando hay diferencias.

Qué puede hacer:

- Ajustar cantidades de productos.
- Corregir errores de stock.
- Registrar cambios reales del almacén.

Cómo usarlo:

1. Abra Ajuste de Inventario.
2. Busque el producto.
3. Ingrese la cantidad correcta.
4. Guarde.

---

## 16. Historial de Cierres

Aquí se revisan cierres anteriores de caja.

Qué puede hacer:

- Ver cierres pasados.
- Revisar montos de cada cierre.
- Consultar quién cerró la caja.

Cómo usarlo:

1. Abra Historial de Cierres.
2. Busque por fecha.
3. Revise los detalles.

---

## 17. Usuarios

Este módulo administra los usuarios que pueden usar el sistema.

Qué puede hacer:

- Crear usuarios nuevos.
- Dar permisos.
- Cambiar datos de acceso.

Cómo usarlo:

1. Abra Usuarios.
2. Cree un nuevo usuario.
3. Asigne nombre, correo y contraseña.
4. Guarde.

---

## 18. Recomendaciones generales

- Siempre cierre sesión cuando termine de usar el sistema.
- No comparta su contraseña.
- Revise bien los datos antes de guardar una venta o compra.
- Si aparece un error, anote el mensaje y repórtelo.
