Control de Caja

Utilice estas herramientas para auditar y cerrar las operaciones de venta del día. El Reporte X es una lectura sin efectos, mientras que el Reporte Z es un cierre definitivo.

Reporte X (Lectura Parcial)

Genera una vista previa de las ventas totales, costos y ganancias desde el último cierre. Esta acción es solo informativa y no modifica ningún dato.

Reporte Z (Cierre Definitivo)

Finaliza el ciclo de ventas actual, registra los totales en el historial y marca todas las ventas como "Cerradas". Esta acción es irreversible.
